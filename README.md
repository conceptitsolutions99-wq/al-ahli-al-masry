# الأهلي مصر لإدارة الأصول العقارية — Landing Page

موقع تعريفي احترافي بالكامل باللغة العربية (RTL) لشركة **الأهلي مصر لإدارة الأصول العقارية**،
مصمم بألوان الشعار (برتقالي + أخضر + ذهبي) على خلفية دافئة مريحة للعين.

## المطابقة لمتطلبات الورقة المكتوبة ✅

- ✅ درس مشاكل العقار (عمارات – إراضي – شقق) وحلها من مكان واحد
- ✅ مستندات الملكية (الرزق – التقسيم الكامل)
- ✅ التعريفات على العقارات والإراضي وإدارتها
- ✅ رفع المسمى ومعرفة صورة الأرض والعقار
- ✅ استخراج تراخيص البناء والعقار والتشييد
- ✅ تسجيل العقارات في الشهر العقاري
- ✅ تراخيص الهدم وتغيير بناء العقار
- ✅ الإيجار والتأجير وإدارة العقود
- ✅ إدارة المرافق (Facility Management)
- ✅ تاريخ إنشاء الشركة: 2009

## متطلبات ملف Word (الاستراتيجية) ✅

- ✅ قوة مؤسسية: مشتقة من مشاركة البنك الأهلي المصري وبنك مصر
- ✅ الشعارات: «خبرة بحجم الأصل» و«قيمة عقارية.. برؤية مؤسسية» و«ثقة مؤسسية.. لقيمة عقارية مستدامة»
- ✅ أهداف الشركة الأربعة (تعظيم القيمة، حلول متكاملة، علاقات طويلة الأمد، مكانة تنافسية)
- ✅ المزايا التنافسية (USPs) ودورة حياة الأصل العقاري كاملة
- ✅ الفئة المستهدفة B2B (شركات خاصة وحكومية)
- ✅ نبرة الصوت: مهني، موثوق، قريب، يركز على الحلول
- ✅ بيانات التواصل من الموقع القديم (هاتف/واتساب/بريد/عنوان)

## لوحة التحكم (Admin Dashboard) ✅

لا حاجة لتعديل الكود — يمكن للمسؤول إدارة كامل محتوى الموقع من لوحة تحكم خاصة:

- **تعديل** جميع نصوص الموقع: الواجهة، خدماتنا، مراحل العمل، لماذا نحن، الأهداف، الفئة المستهدفة، شريط الدعوة، التواصل، الفوتر
- **إضافة وحذف** عناصر القوائم: الخدمات، المراحل، المزايا، الأرقام، بطاقات الثقة، الفئات، بيانات التواصل
- **تحريك** ترتيب العناصر (أعلى/أسفل)
- **تغيير** أيقونات البطاقات من قائمة جاهزة
- **تعديل** بيانات التواصل (رقم الهاتف، واتساب، البريد، العنوان) — يتغير تلقائيًا في الموقع وزر واتساب
- **تعديل** عنوان الصفحة ووصفها في نتائج البحث (SEO)
- **تغيير كلمة المرور** من داخل اللوحة

### الوصول للوحة التحكم

بعد النشر افتح: `https://YOUR-DOMAIN.vercel.app/admin/`

سجّل الدخول بالبريد وكلمة المرور المقدمة من مطوّر المشروع. جميع التعديلات تظهر على الموقع مباشرة بعد الحفظ.

### التقنية الخلفية

- قاعدة بيانات **Supabase** (مجانية — Free tier) لتخزين المحتوى
- **Row Level Security (RLS)**: القراءة عامة لزوار الموقع، والكتابة محمية بتسجيل دخول المسؤول فقط
- الموقع يجلب المحتوى المحفوظ تلقائيًا عند كل زيارة، مع محتوى افتراضي مدمج كاحتياطي إذا تعذر الاتصال

## التقنية

- HTML + CSS + JavaScript خالص (بدون أي إطار عمل) — سرعة فائقة و SEO ممتاز
- تصميم متجاوب بالكامل (موبايل / تابلت / سطح المكتب)
- خطوط Cairo + Tajawal مستضافة محليًا (بدون Google Fonts CDN)
- بيانات منظمة (JSON-LD) لمحركات البحث
- لوحة تحكم عربية RTL بنفس هوية الموقع

## الملفات

```
index.html              الصفحة الرئيسية كاملة
css/style.css           التنسيقات (لوحة الألوان من الشعار)
js/main.js              التفاعل (القائمة، الحركات، النموذج)
js/content.js           طبقة المحتوى — تجلب المحتوى من قاعدة البيانات وتطبّقه
js/content-default.js   المحتوى الافتراضي (احتياطي + نقطة انطلاق اللوحة)
admin/index.html        لوحة التحكم — شاشة الدخول والمحرّر
admin/admin.js          منطق اللوحة (تسجيل دخول + تحرير + حفظ)
admin/admin.css         تنسيقات اللوحة
assets/                 الشعار والأيقونة وصورة المشاركة والخطوط
```

## النشر على GitHub + Vercel

### 1) رفع المشروع على GitHub

```bash
git init
git add .
git commit -m "الأهلي مصر — landing page + admin dashboard"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

### 2) ربط الموقع بـ Vercel

1. افتح [vercel.com](https://vercel.com) وسجّل الدخول بحساب GitHub.
2. اضغط **Add New → Project** واختر المستودع الذي رفعته.
3. اترك الإعدادات كما هي (Vercel يكتشف تلقائيًا أنه موقع ثابت — لا حاجة لبناء).
4. اضغط **Deploy** — ستحصل على رابط مثل `https://project.vercel.app`.

> لاحقًا يمكنك ربط دومين الشركة (alahlymisr.net) من: Project Settings → Domains.

### ملاحظات

- النموذج يرسل الطلبات عبر **واتساب أو البريد** مباشرة من المتصفح (بدون خادم).
- لتغيير محتوى الموقع: استخدم لوحة التحكم من `https://YOUR-DOMAIN.vercel.app/admin/`.
- المحتوى الافتراضي في `js/content-default.js` — يظهر فقط إذا لم يكن هناك محتوى محفوظ في قاعدة البيانات.
